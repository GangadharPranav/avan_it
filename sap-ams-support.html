AVAN Incident Support Matrix

Severity Level Impact Profile Resolution Target Coverage
Severity 1 (Critical) Production system down, core business processes completely halted, revenue loss risk. < 2 Hours Target 24/7/365
Severity 2 (High) Major module degradation (e.g. billing or dispatch delayed), workaround available but urgent. < 8 Hours Target 24/7/365
Severity 3 (Medium) Non-critical issue, single user impacted, reporting exception, standard configuration tweak. < 24 Hours Target Business Hours (9x5 / 16x5)
Severity 4 (Low) Minor feature enhancement request, UI customization, user master maintenance, general guidance. Scheduled Sprint Release Standard Hours
