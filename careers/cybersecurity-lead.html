Cybersecurity Lead

Design zero-trust architectures, coordinate threat audits, govern IAM roles, and secure our enterprise databases and client platforms.

Role Overview

As a Cybersecurity Operations Lead at AVAN, you will build and govern the zero-trust architecture for internal assets and external customer environments. You will set up automated alert logs, run scheduled penetration tests, review compliance alignments, and manage active threat incident response pathways.

Key Responsibilities

  • Formulate zero-trust security postures and enforce multi-factor authentication and strict IAM controls.
  • Coordinate penetration testing cycles across cloud networks and REST/gRPC backend layers.
  • Configure vulnerability scanning scripts and centralize alerts into the Security Operations Centre (SOC).
  • Ensure data architectures satisfy regional compliance mandates (SOC 2 Type II, ISO 27001, GDPR).
  • Build disaster mitigation protocols and direct incident response drills.

Technical Requirements

  • 5+ years of experience in cybersecurity operations, network security, or security consulting.
  • Strong familiarity with network configurations, firewalls, TLS/SSL, and secure tunnels.
  • Hands-on experience with threat detection logging tools (Wazuh, Splunk, Sentinel).
  • Proficient with security audits for major cloud providers (AWS Security Hub, Azure Defender).
  • Respected security certifications (e.g., CISSP, CEH, OSCP, or CISM).
